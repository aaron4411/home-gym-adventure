# 🦖 Home Gym Adventure 🦋

A gamified home-gym app for families — built for kids ages 9–14 (parents welcome). Turn exercise time into an adventure with points, levels, badges, guided courses and age-based targets.

## Features

- **86 exercises** across jump, agility, cardio, core, strength, balance, dance, obstacle, aim & catch, yoga, games and cooldown — from playful (Frog Pond Hop, Angry Birds) to real training (push-ups, sit-ups, burpees, sprints, tuck jumps, ladder drills)
- **Age-based targets** — every exercise has a Rookie (ages 9–10), Pro (11–12) and Elite (13+) target with suggested reps and modifications (e.g. push-ups on knees). Each player sees their own target based on their age
- **What it trains** — each exercise shows the muscle groups (core, back, biceps, quads…), skills (balance, proprioception, hand-eye…) and type of muscle work:
  - 🚀 Blast-Off (explosive power) · 🏋️ Strength Builder · 🧊 Freeze Hold (isometric) · 🔋 Endurance Engine · ⚡ Quick Feet (speed/agility) · 🎮 Skill Practice · 🌀 Stretch & Flex
- **Courses** — guided sets of 4–7 exercises with a countdown timer, pause/resume, Done/Skip, rest breaks and a completion bonus:
  Core & Upper Body, Leg Day, Cardio Blast, Dance Party, Balance Lab, Aim & Throw, Hand-Eye Coordination, Ladder & Agility, Stretch & Recover, Healthy Mix
- **Focus filter** — find exercises by muscle, skill or work type
- **Gamification** — earn XP, level up from Stardust to Universe Champion, unlock 38 badges plus avatar badges
- **Up to 4 players**, equipment filtering, spinning-wheel random pick, favorites, activity notes, mission log

## Equipment Supported

Saucer cones, foam balls, plyo boxes (6"/12"/18"), Bosu ball, yoga mat, yoga blocks, light weights, balance beam, ballet barre, stepping stones, **agility ladder**, and blankets. Many exercises need no equipment at all — music and room lights are assumed, not required.

## How to Use

1. Open the app and go to **Command Center**
2. Add players (name, age, avatar, color) — age sets each player's Rookie / Pro / Elite targets
3. Check off your available equipment
4. Start a **Course** for a guided workout, or pick individual **Missions**

## Tech Stack

- React 18 (from CDN)
- Vanilla CSS with CSS animations
- LocalStorage for data persistence
- Single HTML file (no build required)
